# Simple Architecture (SimpleLabeler)

## Описание

SimpleLabeler - это простая архитектура, использующая скользящие окна (window sliding) для извлечения признаков из геномных последовательностей без использования рекуррентных или трансформерных слоев.

## Назначение

Модель предназначена для базовой классификации геномных последовательностей с использованием простых статистических признаков, извлеченных через скользящие окна различных размеров.

## Архитектура

### Компоненты

1. **WindowSlider**
   - Извлекает признаки через скользящие окна
   - Параметры:
     - `windows`: список размеров окон (например, [5, 10, 20, 50])
   - Процесс:
     - Для каждого размера окна:
       - Применяет padding для сохранения размера
       - Использует `unfold` для создания окон
       - Вычисляет среднее значение в каждом окне
     - Объединяет признаки всех окон

2. **Linear Layer**
   - Проекция признаков из window slider
   - Linear(len(windows) → n_class)

3. **Predictor**
   - Трехслойный перцептрон (аналогично другим моделям)

### Поток данных (Forward Pass)

```
Input (batch, genome_length)
  ↓
WindowSlider → (batch, genome_length, len(windows))
  ↓
Linear → (batch, genome_length, n_class)
  ↓
Predictor → (batch, genome_length, n_class)
  ↓
Output (logits)
```

## Гиперпараметры

- `n_class`: количество классов
- `windows`: список размеров окон для извлечения признаков
- Параметры Predictor

## Функция потерь

- **EMD_squared_loss**: Earth Mover's Distance squared loss (по умолчанию)
- Также может использоваться CrossEntropyLoss

## Особенности реализации

- Не использует рекуррентные или трансформерные слои
- Простое извлечение признаков через скользящие окна
- Быстрое обучение и инференс
- Хорошо работает как baseline модель
- WindowSlider вычисляет локальные статистики (средние значения) для разных размеров окон

## WindowSlider детали

WindowSlider работает следующим образом:
1. Для каждого размера окна `w`:
   - Добавляет padding: `pad = (w - 1) / 2`
   - Применяет `unfold` для создания окон размера `w`
   - Вычисляет среднее значение в каждом окне
2. Объединяет все признаки в тензор размерности (batch, genome_length, len(windows))
