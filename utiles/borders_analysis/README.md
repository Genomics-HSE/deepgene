# Анализ метрик в зависимости от правого граничного интервала

## Описание

Данный анализ исследует поведение метрик **FMSE** (Fractional Mean Squared Error) и **FMAE** (Fractional Mean Absolute Error, также известная как FMSA) для различных моделей нейронных сетей в зависимости от количества используемых временных интервалов.

## Методология

### Идея анализа

Для каждой модели вычисляются метрики FMSE и FMAE на подмножествах данных, начиная с первых 10 интервалов и постепенно увеличивая количество интервалов до максимального (32 интервала). Это позволяет оценить, как качество предсказаний изменяется при включении более глубоких временных интервалов.

### Формулы метрик

#### FMSE (Fractional Mean Squared Error)
```
FMSE = mean((Ne_true - Ne_pred) / Ne_true)²
```

#### FMAE (Fractional Mean Absolute Error) / FMSA
```
FMAE = mean(|(Ne_true - Ne_pred) / Ne_true|)
```

Обе метрики являются относительными ошибками, что позволяет сравнивать значения Ne на разных временных масштабах.

### Обработка данных

1. **Заполнение пропусков**: NaN и Infinity значения заменяются предыдущими валидными значениями
2. **Обрезка массивов**: Удаляются невалидные значения с конца массивов
3. **Фильтрация**: Исключаются точки, где Ne_true = 0 (избежание деления на ноль)

### Временные интервалы

Временные интервалы определяются массивом `limits` из модуля `deepgene.data.data_gen_np`:

```python
limits = [
    0, 700, 1500, 2200, 3000, 3400, 3800, 4200, 4700, 5200,
    5700, 6200, 7200, 8500, 9800, 11000, 12500, 14000, 15500,
    16500, 17500, 18500, 21000, 24000, 27000, 31000, 40000,
    55000, 75000, 95000, 120000, 10000000, 20000000
]
```

Каждый интервал определяется парой соседних значений в `limits`. Например:
- Интервал 0: [0, 700) поколений
- Интервал 1: [700, 1500) поколений
- ...
- Интервал 31: [120000, 10000000) поколений

## Структура данных

### Модели

Анализ включает три типа архитектур нейронных сетей:

1. **GRU** (Gated Recurrent Unit)
2. **LSTM** (Long Short-Term Memory)
3. **Reformer**

Каждый тип модели имеет несколько вариантов:
- Разные функции потерь: `ce` (cross-entropy) и `kl` (Kullback-Leibler divergence)
- Разные наборы данных для обучения: `const`, `hl`, `set1`, `set2`, `set3`

### Демографии

Для каждой модели метрики вычисляются на трех демографиях:
- `const`: постоянная популяция
- `hl`: human-like демография
- `zigzag`: зигзагообразная демография

   - Логарифмическая шкала по обеим осям позволяет лучше визуализировать широкий диапазон значений

### Интерпретация результатов

#### Общие наблюдения

1. **Ранние интервалы (10-15)**: 
   - Обычно показывают более низкие значения ошибок
   - Модели лучше предсказывают недавнюю демографическую историю

2. **Средние интервалы (16-25)**:
   - Постепенное увеличение ошибок
   - Некоторые модели показывают стабильность, другие - рост ошибок

3. **Поздние интервалы (26-32)**:
   - Значительное увеличение ошибок
   - Особенно заметно для интервалов с очень большими временными масштабами (10M+ поколений)
   - Связано с меньшей точностью данных на глубоких временных масштабах

#### Сравнение типов моделей

- **GRU**: Показывает стабильную производительность на ранних и средних интервалах
- **LSTM**: Аналогично GRU, с некоторыми вариациями в зависимости от конфигурации
- **Reformer**: В целом сопоставимая производительность с GRU и LSTM

#### Влияние функции потерь

- **Cross-entropy (ce)**: Обычно показывает более стабильные результаты
- **KL divergence (kl)**: Может показывать более высокие ошибки на глубоких интервалах

## Использование результатов

### Для выбора оптимального временного диапазона

Результаты могут помочь определить оптимальный временной диапазон для оценки моделей:
- Если важна точность на недавних временных масштабах, можно ограничиться первыми 15-20 интервалами
- Для анализа глубокой истории необходимо учитывать возрастающую неопределенность

### Для сравнения моделей

Таблица и графики позволяют:
- Сравнить производительность разных архитектур
- Оценить влияние различных функций потерь
- Выбрать лучшую модель для конкретного временного диапазона

## Примечания

1. **NaN значения**: Некоторые интервалы могут содержать NaN значения в Ne_true или Ne_pred, что обрабатывается специальными функциями заполнения

2. **Временные масштабы**: Последние интервалы охватывают очень большие временные масштабы (до 20 миллионов поколений), где точность данных снижается

3. **Усреднение**: В таблице и графиках используется усреднение по демографиям для каждой модели, что дает общую картину производительности

4. **Логарифмическая шкала**: Графики зависимости от временных лимитов используют логарифмическую шкалу по оси X для лучшей визуализации широкого диапазона значений

## Заключение

Анализ показывает, что:
- Модели лучше работают на недавних временных масштабах (первые 15-20 интервалов)
- Производительность снижается при включении глубоких временных интервалов
- Различия между типами моделей относительно невелики
- Выбор оптимального временного диапазона зависит от конкретной задачи
